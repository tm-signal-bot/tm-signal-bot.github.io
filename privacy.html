Data and access

Privacy information

TM Signals VPS Backups is a private backup utility controlled by the operator. It uses Google Drive to store encrypted recovery archives.

Google data and permission

The only requested Google API scope is drive.file. It permits access to files created by this app, or files explicitly selected and authorized for this app. The utility uses that access to upload, read and verify its backup files.

It does not request broad Drive access or permission to read Gmail, contacts or calendars. It does not scan unrelated Drive files. A folder setting alone does not grant access to files outside this permission.

What is stored, and where

The archive contains a consistent copy of application history and approved configuration and deployment files needed for recovery. Restic encrypts the archive on the VPS before it is uploaded to Google Drive.

The VM6 server holds the live application data and the encryption key used by the backup job. Anyone who gains sufficient server access may be able to read that data or key. Encryption does not make a compromised server safe.

Google OAuth tokens are kept privately on the VM6 server. They are never included in the backup archive. An independent copy of the recovery key must be kept separately so backups can be opened if the server is lost.

Google may still see storage metadata such as encrypted object filenames, file sizes and upload or modification times. Encryption protects archive contents; it does not hide every storage detail.

Retention, revocation and deletion

Automatic remote pruning is not enabled. Backup files remain until the operator deletes them or adopts a separate retention policy.

The operator can revoke the app’s access through their Google account permissions and delete backups manually in Google Drive. Revoking access stops future authorized access; it does not delete existing backups. Deleting Drive files does not remove copies retained separately on the server or elsewhere. Google’s trash and retention behavior applies to files removed from Drive.

Use of data and these pages

Backup data is used for storage, verification and recovery. It is not sold, used for advertising or shared with unrelated parties. Google stores the uploaded encrypted files; VM6 hosts the running server.

These static pages contain no advertising, analytics, tracking code, forms or external assets. Once published, their hosting provider may record standard website request logs.

For access or deletion questions, contact the operator using the support contact shown on the Google consent screen.
