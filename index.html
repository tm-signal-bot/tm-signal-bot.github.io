Private backup utility

TM Signals VPS Backups

A private, operator-owned utility that keeps encrypted copies of the operator’s server data in their chosen Google Drive location.

What the utility does

It prepares a consistent copy of application history and approved recovery files on the server, encrypts the backup archive, then uploads it to Google Drive. A backup is recorded as successful only after checks of the uploaded copy.

This utility is for the operator’s own use. There is no public registration or access request on these pages.

Limited Google Drive access

The utility requests only drive.file: access to files it creates, or files explicitly selected and authorized for it. It does not request access to the whole Drive, Gmail or contacts.

The operator stays in control

The operator can revoke Google access and delete stored backups manually. Automatic remote pruning is not enabled.

Read the details

The privacy page explains data, encryption and access. The usage notes explain operation and recovery responsibilities.

For questions, use the support contact shown on the Google consent screen.
